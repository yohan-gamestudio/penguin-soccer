# FLOE · 펭귄 축구

Three.js로 렌더링하는 3D 펭귄 경기장과 브라우저에서 즐기는 1대1 / 2대2 동시 턴제 축구. 각 플레이어가 펭귄 하나를 조종합니다.

## 실행

Node.js 22 이상에서 `npm ci` 후 `npm start`. http://localhost:3000 에 접속합니다.

## Docker

```sh
docker build -t penguin-soccer:1.0 .
docker run --rm -p 3000:3000 --name penguin-soccer penguin-soccer:1.0
```

환경변수 `PORT` 기본값은 3000. HTTP와 WebSocket이 같은 포트를 사용합니다. 상태 확인은 `/healthz`입니다. HTTPS는 앞단 프록시에서 종료하고 WebSocket 업그레이드를 허용해 주세요. 이미지에는 비루트 사용자와 SIGTERM 처리가 포함됩니다.

방은 메모리에 저장되므로 레플리카 1개로 실행합니다. 재시작하면 방이 사라집니다. 일시적인 연결 종료나 새로고침 시 30초 동안 선수 자리를 보관하고 경기와 타이머를 정지합니다. 같은 브라우저 탭은 sessionStorage의 복귀 키로 자동 복귀하여 점수·위치·확정한 조준을 유지합니다. 유예 시간 초과 또는 명시적인 나가기는 경기를 대기실로 돌립니다. 모든 사람이 시간 내 복귀하지 않으면 방이 삭제됩니다. 서버 재시작을 넘는 복구는 지원하지 않습니다.

## 플레이

닉네임 입력 → 모드 선택 → 새 경기 생성 → 친구에게 6자리 코드 전달 → 팀 확인 → 모두 준비. 대기실에서 내 이름을 누르면 빈자리가 있는 반대 팀으로 이동합니다.

내 펭귄에서 뒤로 드래그하고 준비 완료를 누릅니다. 두 모드 모두 조준 제한은 30초이며, 모두 준비하면 남은 시간과 관계없이 즉시 동시에 발사합니다. 제한 시간이 지나도 자동으로 발사합니다. 미입력은 대기, 아군의 확정 방향만 공유됩니다. 3골 선취, 또는 3분 이후 턴 종료 시 점수가 높은 팀 승리. 동점이면 다음 골까지 진행합니다. 벽 반사와 몸싸움이 가능하며 낙사는 없습니다.

`npm test`로 물리·멀티플레이 테스트를 실행합니다. 첫 버전에는 자동 매칭, 계정, 랭크, 서버 재시작 시 경기 복원은 포함하지 않습니다.

## 3D 화면과 조작

빙판·골대·팀 머플러를 착용한 펭귄을 3D로 표시합니다. 물리는 서버의 평면 계산을 유지하며, 브라우저는 위치를 보간하고 슬라이딩·대기·득점 동작을 표시합니다. WebGL2 지원 브라우저가 필요합니다. Three.js는 이미지에 포함되어 외부 CDN 연결이 필요하지 않습니다.

상단 소리 버튼으로 준비·발사·득점·마지막 5초 효과음을 켤 수 있습니다. 기본값은 음소거입니다. 대기실 방 코드 버튼은 코드를 복사합니다. 모바일은 세로 화면에 맞게 카메라와 하단 조작부가 조정됩니다.

클립보드 API가 차단되면 방 코드 선택 창을 표시합니다. PC는 Ctrl+C/⌘C, 모바일은 길게 눌러 직접 복사할 수 있습니다.
